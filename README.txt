CastorSteel — статическая версия сайта

Загрузка на хостинг:
1. Распакуйте архив.
2. Загрузите index.html, styles.css, script.js и папку assets в корневую папку сайта.
3. Стартовая страница — index.html.

Сайт не требует Node.js, базы данных или установки библиотек.
Форма заявки открывает почтовую программу посетителя. Для автоматической отправки заявок подключите форму к обработчику вашего хостинга или CRM.
